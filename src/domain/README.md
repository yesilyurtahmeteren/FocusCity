# Domain

Saf TypeScript iş kuralları bu katmana aittir. React, React Native, Router ve servis bağımlılığı içermez. `focus/session.ts` oturum geçişleri ve kayıt doğrulamasını; `economy/` tam sayı ödül/ledger/dönem hesaplarını; `map/` katalog, footprint, BFS, taşıma ve harita harcamalarının replay'ini içerir. Bu katmanlar UI veya depolama çağırmaz. Harita planları henüz emek yatırımıyla tamamlanmaz; sosyal ve gelişmiş hizmet sistemleri sonraki fazlara aittir.
